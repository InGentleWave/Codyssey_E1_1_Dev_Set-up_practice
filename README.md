## 개요
이 프로젝트를 통해 개발 환경 세팅을 수행하면서 다음을 배웁니다.
### 필수 학습 항목

- **터미널 조작**: 명령어로 파일 시스템을 다루는 기본 능력
- **파일 권한 관리**: 파일 접근을 제어하고 팀과 안전하게 공유하는 방법
- **Docker 운영**: 이미지 빌드, 컨테이너 실행, 포트 매핑으로 환경 일관성 유지
- **데이터 영속성**: 볼륨과 바인드 마운트로 데이터 손실 방지 및 환경 재현
- **Git & GitHub**: 코드 버전 관리 및 팀 협업 능력

### 보너스 학습 항목

- **Docker Compose**: 멀티 컨테이너 자동화 및 로컬 개발 환경 구성
- **SSH 인증**: 안전한 원격 저장소 접근 방법

## 과제 목표 달성 자가 체크리스트
- [ ] 절대 경로와 상대 경로의 차이를 예시를 들어 설명할 수 있다.
- [ ] 파일 권한의 의미(r/w/x)와 755, 644 같은 표기가 어떤 규칙으로 해석되는지 설명할 수 있다.
- [ ] 기존 Dockerfile을 기반으로 “커스텀 이미지”를 만들 수 있다.
- [ ] 포트 매핑이 필요한 이유를 설명할 수 있다.
- [ ] Docker 볼륨(영속 데이터)을 설명할 수 있다.
- [ ] Git과 GitHub의 역할 차이(로컬 버전관리 vs 원격 협업 플랫폼)를 설명할 수 있다.
